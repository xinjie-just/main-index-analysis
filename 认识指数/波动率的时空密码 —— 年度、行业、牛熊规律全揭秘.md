# 年度 / 行业 / 牛熊规律

前面三篇我们分别讲了**波动率全景、低波动优势、高波动风险**。
这一篇，我用你**73只指数、2014—2025完整真实数据**，把波动率的**时间规律、行业规律、牛熊规律**一次性讲透。
看完这篇，你能一眼判断：
现在市场是高波动还是低波动、该配稳的还是冲的。

## 一、时间密码：哪些年份最“疯”？哪些年份最“稳”？

先看**全市场平均年度波动率**（73只指数平均值）：

| 年份     | 平均波动率 | 波动等级 | 市场特征   |
| -------- | ---------- | -------- | ---------- |
| 2014     | 20.7%      | 偏低     | 牛市启动   |
| **2015** | **32.2%**  | **极高** | 疯牛+股灾  |
| 2016     | 26.8%      | 偏高     | 熔断+修复  |
| 2017     | 15.7%      | 极低     | 蓝筹慢牛   |
| **2018** | **30.9%**  | **极高** | 全年熊市   |
| 2019     | 24.6%      | 中等     | 震荡反弹   |
| 2020     | 27.1%      | 偏高     | 疫情波动   |
| 2021     | 24.8%      | 中等     | 结构牛市   |
| **2022** | **29.7%**  | **高**   | 连续下跌   |
| 2023     | 20.9%      | 偏低     | 震荡磨底   |
| 2024     | 27.1%      | 偏高     | 行业轮动快 |
| 2025     | 19.4%      | 极低     | 企稳收敛   |

### 核心规律（直接记）

1. **三大高波动年份：2015、2018、2022**
   要么疯牛见顶，要么全面熊市，波动都**≥30%**。
2. **三大低波动年份：2017、2023、2025**
   市场平稳、慢牛、磨底、收敛，波动率**≤21%**。
3. **波动率越高，越容易亏钱**
   高波动年份几乎都是**大跌或剧烈震荡**；低波动年份反而**收益更稳**。

## 二、行业密码：谁最稳？谁最疯？（数据不骗人）

我把你73只指数按**风格/行业**重新归类，统计**12年平均波动率**：

### 1）波动率最低（最稳）：红利/价值/金融/宽基

- 中证现金流、A500现金流、红利质量、红利低波
- 中证银行、800金融、沪深300、中证A500
- **平均波动率：17%～21%**

### 2）波动率中等（平衡型）：消费、医药、家电、农业

- 800消费、家用电器、CS生医、800医卫、中证农业
- **平均波动率：22%～26%**

### 3）波动率最高（最猛）：科技、赛道、周期、小微盘

- 半导体、新能、创业板、军工、软件、数据、有色、稀金属
- **平均波动率：29%～36%**

### 一句话行业波动排名

**红利/金融 < 消费/医药 < 制造/工业 < 科技/赛道/周期 < 小微盘成长**

## 三、牛熊密码：波动率在牛熊里怎么走？

用12年数据，我总结出**A股牛熊波动率四阶段**，非常实用：

### 1）熊市底部：波动率开始回落

- 市场不创新低、恐慌减少
- 波动率从高位**慢慢往下走**
- 信号：可以**慢慢布局**

### 2）牛市初期：波动率温和上升

- 震荡上行、赚钱效应回升
- 波动率**20%～25%** 最舒服
- 信号：**持股/持基不动**

### 3）牛市末期/高位：波动率突然飙升

- 指数大起大落、单日暴涨暴跌
- 波动率**突破30%**
- 信号：**危险，减仓、防御**

### 4）熊市主跌：波动率持续高位

- 持续下跌、反弹无力
- 波动率**居高不下**
- 信号：**管住手，别抄底**

### 极简口诀

**低波动→放心拿；高波动→快逃命；波动率飙升→快减仓。**

## 四、关键结论：波动率=市场情绪温度计

这一章是整篇最值钱的部分，建议截图保存：

1. **波动率越低，市场越健康，越适合长期持有**
2. **波动率越高，市场越疯狂，越容易大亏**
3. **行业波动率天生固定**
   - 想稳：选**红利、金融、价值、低波**
   - 想冲：选**科技、赛道、周期**
4. **高波动年份一律防御，低波动年份大胆持有**

## 五、实战用法：看波动率做配置（直接照做）

- 当市场波动率 **>28%**（高危）
  → 70%以上仓位：**低波动指数（红利/金融/宽基）**
- 当市场波动率 **21%～28%**（中性）
  → 50%低波 + 50%中波
- 当市场波动率 **<21%**（平稳）
  → 可以适度增加**中高波动行业**
