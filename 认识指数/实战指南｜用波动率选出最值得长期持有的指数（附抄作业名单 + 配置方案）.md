## 一、先给结论：最值得长期持有的指数，只有一类

**低波动 + 正收益 + 小回撤**
三个条件同时满足，就是长期赚钱的“压舱石”。

我用数据定下**可直接复制的筛选标准**：

1. **12年平均波动率 ≤ 21.5%**（够稳）
2. **12年年化收益率 ≥ 7.3%**（跑赢平均）
3. **最大年度回撤 ≥ -22%**（抗跌）
4. **风格：红利 / 现金流 / 价值 / 低波 / 优质宽基**

用这4条，我从73只里**一次性筛出最终优质名单**。

## 三、3套直接抄作业的配置方案（按风险直接选）

我按你73只指数的真实表现，做好**现成组合**，公众号读者可直接用。

### 方案1：极致稳健型（老人/新手/怕亏）

- 仓位：**100%低波动**
- 配置：
  - 中证现金流 25%
  - A500现金流 25%
  - 红利低波100 25%
  - 中证银行 25%
- 特点：波动率≈18%，回撤小，长期年化≈8%–10%

### 方案2：平衡优选型（最推荐，大多数人适用）

- 仓位：**70%低波 + 30%中波**
- 配置：
  - 中证红利质量 25%
  - 300红利质量 20%
  - 消费红利 15%
  - 中证A500 / 沪深300 20%
  - 中波消费/医药 20%
- 特点：收益稳、弹性够，长期年化≈9%–11%

### 方案3：核心卫星型（想冲一点但不冒大险）

- 仓位：**80%低波 + 20%高波**
- 配置：
  - 低波动白名单 80%
  - 半导体/新能源/创业板 合计不超20%
- 特点：稳中带冲，高波只做小仓位博弈

## 四、定投怎么选？一张表说清

| 指数类型          | 定投适合度 | 原因                   |
| ----------------- | ---------- | ---------------------- |
| 低波动红利/现金流 | ⭐⭐⭐⭐⭐ | 波动小、成本稳、拿得住 |

## 五、最简单的3条实战纪律（看完就能用）

1. **只在白名单里选，不碰高波动重仓**
2. **组合整体波动率控制在 22% 以内**
3. **波动率飙升时（>28%），减仓、加低波、降风险**

记住一句话：
**收益决定赚多少，波动率决定能不能拿住。**
